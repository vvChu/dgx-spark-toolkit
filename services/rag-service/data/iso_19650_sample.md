# ISO 19650 Summary: Organization and Digitization of Information about Buildings and Civil Engineering Works

ISO 19650 is an international standard for managing information over the whole life cycle of a built asset using building information modelling (BIM). It contains all the same principles and high-level requirements as UK BIM Framework and is closely aligned with the current UK 1192 standards.

## Part 1: Concepts and Principles
ISO 19650-1 outlines the concepts and principles for information management at a stage of maturity described as "BIM according to the ISO 19650 series". This establishes the core framework for standardizing data and organizing project information.

## Part 2: Delivery Phase of the Assets
ISO 19650-2 specifies requirements for information management, in the form of a management process, within the context of the delivery phase of assets and the exchanges of information within it, when using building information modelling.

## Part 3: Operational Phase of the Assets
ISO 19650-3 specifies requirements for information management, in the form of a management process, within the context of the operational phase of assets and the exchanges of information within it, when using building information modelling.

## Part 4: Information Exchange
ISO 19650-4 specifies the detailed requirements for information exchange, guiding how data should be formatted and shared between different stakeholders across the project lifecycle.

## Part 5: Security-Minded Approach
ISO 19650-5 specifies the principles and requirements for security-minded information management. It ensures that sensitive building data is protected against malicious access and provides a framework for secure collaboration.

## Information Requirements
A key concept in ISO 19650 is the definition of Information Requirements. These include:
- OIR: Organizational Information Requirements
- AIR: Asset Information Requirements
- PIR: Project Information Requirements
- EIR: Exchange Information Requirements

## Common Data Environment (CDE)
The Common Data Environment (CDE) is the single source of information for any given project or asset, used to collect, manage and disseminate all relevant approved project documents for multi-disciplinary teams. A CDE workflow ensures that information is only shared when appropriate and that previous versions are archived.
